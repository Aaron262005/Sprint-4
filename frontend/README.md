# Sprint4 – Frontend (Angular, MVVM)

Estos archivos son el CÓDIGO FUENTE (`src/`) que se coloca sobre un workspace de Angular.

## Cómo usarlo en Visual Studio Code
1. Genera el workspace (una sola vez):
   ng new frontend --routing --style=scss
   (responde N a analíticas, N a SSR, y "None" a herramientas de IA)
2. Copia la carpeta `src/` de este zip encima de `frontend/src/` (reemplazando archivos).
3. cd frontend
   npm install
   ng serve
4. Abre http://localhost:4200/login  (el backend debe estar corriendo en https://localhost:7000)

Si ya clonaste el repositorio del equipo, NO necesitas este zip: solo entra a la carpeta
`frontend`, ejecuta `npm install` y `ng serve`.

Ver la guía completa (Guia_Trabajo_Equipo_Sprint4.pdf) para el flujo de ramas y Git.
